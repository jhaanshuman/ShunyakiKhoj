1. Panini's Ashtadhyayi & Generative Architecture

The Ashtadhyayi consists of 8 chapters (Adhyayas), each divided into 4 quarter-sections (Padas), yielding 32 Padas containing ~4,000 algorithmic rules. Panini used Shiva Sutras to define phoneme classes (Pratyaharas) and established ordered rule execution (Asiddhavat & Tripadi rules) that modern computer scientists compare to context-free formal programming languages.

2. Dhatu-Patha: The 2,000 Verbal Roots

All Sanskrit nouns, verbs, and adjectives derive from ~2,000 primitive verbal roots called Dhatus, categorized into 10 verbal classes (Ganas):

  • Bhvadi Gana: Root 'Bhū' (to be, exist).
  • Adadi Gana: Root 'Ad' (to eat).
  • Juhotyadi Gana: Root 'Hu' (to offer in Yajna).
  • Divadi Gana: Root 'Div' (to shine, play).
  • Svadi Gana: Root 'Su' (to extract, press).
  • Tudadi Gana: Root 'Tud' (to strike).
  • Rudhadi Gana: Root 'Rudh' (to obstruct).
  • Tanadi Gana: Root 'Tan' (to stretch, expand).
  • Kryadi Gana: Root 'Krī' (to buy).
  • Churadi Gana: Root 'Chur' (to steal).

3. Sandhi: Euphonic Phonetic Combination

Sandhi ('joining') governs how sounds blend naturally at word and morpheme boundaries. The 3 main divisions are:

  • Svara Sandhi (Vowel Sandhi): Combines vowels (e.g., Deva + Alaya = Devalaya [Dirgha], Maha + Isha = Mahesha [Guna]).
  • Vyanjana Sandhi (Consonant Sandhi): Assimilates voiced/unvoiced consonants (e.g., Sat + Chit = Satchit).
  • Visarga Sandhi: Transforms Visarga (:) into 'o', 'r', 's', 'sh', or drops it (e.g., Namah + Te = Namaste).
